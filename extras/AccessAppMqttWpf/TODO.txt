NEW MQTT COMMANDS – AccessAPP

1) Remove device(s) from upgrade queue

Command topic:
{baseTopic}/{networkId}/cmd/{target}/remove-from-queue

- target can be a cassia name (e.g. cassia-01) or "all"
- Removes only pending queue items (does not stop active programming)

Payload examples:

Single MAC as string:
"10:B9:F7:11:08:3B"

Single MAC as object:
{ "macAddress": "10:B9:F7:11:08:3B" }

Multiple MACs as object:
{ "macAddresses": ["10:B9:F7:11:08:3B", "10:B9:F7:AA:BB:CC"] }

Multiple MACs as array:
["10:B9:F7:11:08:3B", "10:B9:F7:AA:BB:CC"]

Response topic:
{baseTopic}/{networkId}/tele/{name}/queue-remove

Response example:
{
  "success": true,
  "removed": 1,
  "requested": ["10:B9:F7:11:08:3B"]
}

------------------------------------------------------------

2) Get full device list (single message)

Command topic:
{baseTopic}/{networkId}/cmd/{target}/get-device-list

Optional payload:
{ "requestId": "abc123" }

Response topic:
{baseTopic}/{networkId}/tele/{name}/device-list

Response payload example:
{
  "count": 42,
  "deviceList": [
    {
      "macAddress": "10:B9:F7:11:08:3B",
      "rssi": -61,
      "detectorType": "P46",
      "detectorFamily": "DALI",
      "productNumber": "353-0232",
      "name": "Detector-1",
      "lastSeenUtc": "2026-01-15T20:59:12Z",
      "isStale": false
    }
  ]
}

------------------------------------------------------------

Notes:
- target = "all" broadcasts the command to all Cassia gateways
- Device list is returned in one MQTT message (not chunked)
- Queue removal is thread-safe and does not affect active upgrades
